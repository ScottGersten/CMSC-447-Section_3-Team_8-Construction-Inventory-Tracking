# CMSC-447-Section_3-Team_8-Construction-Inventory-Tracking

## Setup
- Install Flutter SDK
    - Can be done by installing Flutter and Dart extensions in VS Code, which will prompt with installation.
    - Or Navigate to https://docs.flutter.dev/install.
    - Then extract the download to a dedicated directory on the deployment machine.
    - Edit the environment variables Path to the flutter\bin file.
    - Run `flutter doctor` to analyze the environment. Install specific dependencies if needed.
- Run Application:
    - Run `flutter run` to run the application. Select option `2` to deploy to Chrome.
